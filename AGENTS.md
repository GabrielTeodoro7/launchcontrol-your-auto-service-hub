# Orientações do projeto LaunchControl

- A implementação independente desta entrega fica em `launchcontrol-servlet/` e utiliza Java 17, Jakarta Servlets, JDBC/MySQL, HTML, CSS e JavaScript puro.
- Não introduza React, TypeScript, Vite, TanStack Router, Node.js, Express ou Spring Boot na implementação independente.
- O aplicativo web que já existe na raiz é um projeto separado; não misture seus arquivos com a aplicação Java Servlet.
- Não reescreva o histórico publicado nem force push. Trabalhe em branches e commits normais.
- Mantenha a documentação honesta: distinguir código implementado de funcionalidade testada em execução real.
- Ao alterar o código, prefira comentários em português claro, voltados a quem está aprendendo programação.
- Não adicione dados falsos apresentados como reais, credenciais padrão ou integrações externas que não tenham sido configuradas.
